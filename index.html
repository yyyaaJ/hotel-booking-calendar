🔧 ตั้งค่า Firebase

กรอก Firebase Config เพื่อเชื่อมต่อฐานข้อมูล (ข้อมูลจะถูกเก็บใน localStorage สำหรับครั้งต่อไป)

⚠️ ต้องเปิดใช้ Realtime Database ใน Firebase Console
🔒 อย่าตั้ง Rules แบบเปิด public (".read": true, ".write": true) บนข้อมูลจริง เพราะข้อมูลลูกค้า (ชื่อ/เบอร์โทร) จะถูกอ่านหรือลบได้โดยทุกคน — แนะนำให้เปิด Authentication แล้วจำกัดสิทธิ์
🔒 Config จะเก็บใน localStorage ของเบราว์เซอร์นี้เท่านั้น
